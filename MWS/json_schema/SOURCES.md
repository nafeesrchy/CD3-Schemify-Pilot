# Sources — CD3 pilot: Million Women Study

## Dictionary files

- `millionwomenstudydatadictionary-v1-21.xlsx` (copied to `CD3_Schemify_Pilot/MWS/raw_data/`, v1.21, dated 05/11/2024) · Excel, 6 sheets (`Basic information`, `Recruitment variables`, `Self-reported health at recruit`, `3-year resurvey`, `Dietary data at 3-year resurvey`, `8-year resurvey`). Scope, by table:
  - **`recruitment` table**: `Basic information` (7 vars), `Recruitment variables` (38 vars), `Self-reported health at recruit` (20 vars) — 65 variables, one row per participant at baseline recruitment.
  - **`resurvey_3yr` table**: `3-year resurvey` (135 vars, sheet's own title "3-year (yellow) resurvey") + `Dietary data at 3-year resurvey` (14 vars, all derived nutrient/food-intake measures, "Derived" availability across all 4 questionnaire versions, no stated ranges or codes on any of them) — 149 variables, one row per participant at the 3-year follow-up wave. Re-plan added 2026-09-16 (see DECISIONS.md).
  - **`resurvey_8yr` table**: `8-year resurvey` (38 vars, sheet's own title "8-year (lilac) resurvey") — one row per participant at the 8-year follow-up wave. Re-plan added 2026-09-17 (see DECISIONS.md).
  All in-scope sheets share the same layout: title/version on rows 1-2, sheet label row 3, real header on row 4 (`Field Name` split into `Short`/`Long` sub-columns on row 6, `Description`, `Valid range` split into `From`/`To` on row 6, `Availability for questionnaire versions:` split into version sub-columns on row 5, with version-year ranges on row 7 and numeric availability fractions on row 6, `Code list`), data starting row 8. Code lists are packed into a single cell as newline-separated `code=label` pairs, not one row per code. `recruitment`'s questionnaire versions are Aqua/Blue/Other; `resurvey_3yr`'s are 4 numeric codes (9903, 9907, 9909, 0012); `resurvey_8yr`'s are only 2 (0512, 0605), and its own code list literally reuses the version tag as the code value itself (`512=0512`, `605=0605`) rather than a small ordinal — a third, distinct versioning convention. `RAGE` (Basic information) is the one field seen with a one-sided valid range (`From=48`, no `To`); none of the 14 dietary variables state a range at all; `resurvey_8yr`'s `F2HTLU` is the only field in that sheet with a source-stated range (0-40). No participant-identifier field exists in any of the three later sheets either — same gap as `recruitment` (D007/D047). `resurvey_8yr` is noticeably smaller than `resurvey_3yr` and drops several of its blocks entirely (medications, parental mortality, early life, socioeconomic/activities, wellbeing/sleep) -- family history shrinks to breast cancer only, but adds a sister field (`F2SCABR`) alongside mother/father, a relative not asked about in either other table. Extracted via direct XML parsing of the xlsx zip. Registered 2026-09-15 (recruitment), 2026-09-16 (resurvey_3yr), 2026-09-17 (resurvey_8yr).
